# mydoctorpal

A full-stack hospital health record frontend for the supplied Spring Boot backend. The frontend is React + Vite + JavaScript + Tailwind CSS and uses exact `/api/v1` contracts from the project specification.

## Run

```bash
cd frontend
npm install
npm run dev
```

Set `VITE_API_BASE_URL` in `.env` if the backend is not running at `http://localhost:8080/api/v1`.
